## Paano mag-aral sa Filipino

- Buksan ang kahit anong aralin at pindutin ang globe button 🌐 sa itaas. Piliin ang Filipino para mabasa ang salin. Pareho pa rin ang code.
- Pindutin ang Run sa mga halimbawa, baguhin ang code at tingnan ang resulta. Walang kailangang i-install.
- Gawin ang maikling exercise sa dulo ng bawat aralin, saka lumipat sa susunod.
- Panoorin ang mga video lesson sa YouTube channel na [CoderSantoshAdhikari](https://www.youtube.com/channel/UCo6suGrveQ0HFf46wfGBKXA).
