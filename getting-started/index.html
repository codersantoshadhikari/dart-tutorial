    Getting Started with Dart

    What Dart is, how to install it, and how to write, run and comment your first program.

    This chapter gets Dart running on your computer and walks you through your first program. You do not need any programming experience. If you would rather not install anything yet, every example on this site that has a Run button opens in DartPad, the official online editor.

    Lessons in this chapter

    1. What Is Dart? An Introduction to the Dart LanguageDart is a typed, object-oriented language from Google used to build mobile, web, desktop and server apps. Learn what it is and why people use it.
    2. How to Install Dart on Windows, macOS and LinuxStep-by-step guide to installing the Dart SDK on Windows, macOS and Linux, checking the version, and setting up VS Code.
    3. Your First Dart Program: Hello World ExplainedWrite Hello World in Dart and understand every part of it: the main function, print, statements, semicolons and how to run the file.
    4. Comments in Dart: Single-Line, Multi-Line and Doc CommentsLearn the three kinds of comments in Dart, when to use each, and how documentation comments turn into API docs.
    5. Dart Syntax: The Basic Rules of Dart in One PageLearn Dart syntax fast: program structure, semicolons, variables, types, strings, if else, loops, functions, classes and null safety, with easy examples.
    6. Dart vs JavaScript: Key Differences Explained with CodeDart vs JavaScript compared side by side: types, null safety, variables, strings, classes, async await, performance and when to choose each. Easy examples.
    7. Dart vs Python: Differences, Code Comparison and Which to LearnDart vs Python compared with side-by-side code: syntax, types, null safety, lists, classes, async, speed and jobs. Find out which language to learn first.
