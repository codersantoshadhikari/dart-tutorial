## Learn Dart online: a free Dart tutorial for beginners

This Dart tutorial teaches the **Dart programming language** from zero, then the **Flutter** framework for building apps for Android, iOS, the web and desktop from one codebase. You do not need any programming experience. Each lesson explains one idea in plain English, shows it in a short Dart example with its output, and ends with an exercise.

It works as a complete **Dart programming course**: Dart basics to advanced topics, in the right order, written in simple English. It is also the best way to **learn Dart for Flutter**, because every Flutter app is written in Dart.

Not sure where to begin? Follow the free Dart and Flutter roadmap, or open the Dart online compiler and start typing.

## What you will learn

In the Dart course (learn Dart programming):

- Dart basics: Dart syntax, variables, data types, strings and string methods, numbers and operators.
- Control flow: if else, loops, switch and the ternary operator.
- Functions and collections: Dart functions, parameters, closures, lists and list methods, sets and maps.
- Null safety: How Dart null safety stops null errors before your program runs.
- Dart OOP: Classes and objects, constructors, inheritance, interfaces, mixins, enums, generics and extensions.
- Modern Dart 3: Records, patterns, switch expressions, sealed classes and class modifiers.
- Asynchronous code: Future, async and await, streams, the event loop and isolates.
- Practical skills: Files, JSON, HTTP requests, dates, regular expressions, packages, testing and debugging.

In the [Flutter tutorial](https://flutter.dart-tutorial.dev/) (learn Flutter step by step, on flutter.dart-tutorial.dev):

- Widgets and layout: Stateless and stateful widgets, rows, columns, stacks, lists, grids and slivers.
- Material Design: App bars, navigation, dialogs, themes and dark mode.
- Input and navigation: Forms, validation, gestures, routes and go_router.
- State management: All 9 built-in tools and 20 packages: Riverpod, Bloc and Cubit, Provider, GetX, MobX, Signals, Redux and more.
- Data: HTTP, JSON models, loading states, local storage, SQLite and Firebase.
- Polish: Animations, responsive layouts for phones, tablets and desktop, accessibility and localization.
- Shipping: Testing, performance, architecture, and releasing on Android, iOS and the web.
- Games: 2D game development with the Flame engine and five complete games.

## How to use this site

Read the lessons in order the first time. Run every example and change it to see what happens: that is where most of the learning takes place. Use the search box, or press `/`, to jump to a topic in either course. Mark lessons as done to keep track of where you are. Your progress is stored in your own browser and nowhere else.

Learners use Dart Tutorial from the USA, Canada, the UK and Europe, Australia, India, Nepal and everywhere else Flutter is used. The lessons are in simple English so they are easy to follow wherever you are.
