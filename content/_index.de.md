## So lernst du auf Deutsch

- Öffne eine beliebige Lektion und tippe oben auf den Globus 🌐. Wähle Deutsch, um die Lektion übersetzt zu lesen. Der Code bleibt gleich.
- Drücke bei den Beispielen auf Run, ändere den Code und sieh dir das Ergebnis an. Keine Installation nötig.
- Mach die kleine Übung am Ende jeder Lektion und geh dann zur nächsten.
- Sieh dir die Video-Lektionen auf dem YouTube-Kanal [CoderSantoshAdhikari](https://www.youtube.com/channel/UCo6suGrveQ0HFf46wfGBKXA) an.
