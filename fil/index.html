    Dart Tutorial sa Filipino: Matuto ng Dart Programming nang Libre

    Matuto ng Dart mula sa simula, hakbang-hakbang: variables, functions, OOP, null safety at async, may libreng halimbawang tumatakbo sa browser.

    Simulan ang kurso sa Dart Kurso sa Flutter

    Ang iyong learning path, hakbang-hakbang

    1. Pagsisimula

      Ano ang Dart, paano ito i-install, ang syntax at ang iyong unang program.

    2. Mga batayan ng Dart

      Variables, data types, strings, numbers, operators at input ng user.

    3. Control flow

      if/else, loops, switch, break/continue at ternary operator.

    4. Functions

      Parameters, arrow functions, closures, higher-order functions at recursion.

    5. Collections

      List, Set, Map, iterables at where/map/reduce.

    6. Null safety

      Nullable types, null-aware operators at late: code na hindi nagka-crash dahil sa null.

    7. Object-oriented programming

      Classes, constructors, inheritance, mixins, enums at generics.

    8. Asynchronous programming

      Futures, async/await, streams, event loop at isolates.

    Paano mag-aral sa Filipino

    • Buksan ang kahit anong aralin at pindutin ang globe button 🌐 sa itaas. Piliin ang Filipino para mabasa ang salin. Pareho pa rin ang code.
    • Pindutin ang Run sa mga halimbawa, baguhin ang code at tingnan ang resulta. Walang kailangang i-install.
    • Gawin ang maikling exercise sa dulo ng bawat aralin, saka lumipat sa susunod.
    • Panoorin ang mga video lesson sa YouTube channel na CoderSantoshAdhikari.
