    Tools and Performance

    Format, lint, debug, log and profile your Dart code, and understand how memory and garbage collection work.

    Writing code is half the job. The other half is keeping it tidy, finding out why it misbehaves, and making it fast enough. Dart’s tooling is one of its strengths.

    Lessons in this chapter

    1. Formatting and Linting Dart Code: dart format and dart analyzeKeep Dart code clean with dart format, dart analyze, lints and dart fix. Learn to configure analysis_options.yaml for your project.
    2. Debugging Dart Code: Breakpoints and Dart DevToolsLearn to debug Dart with breakpoints, stepping, watches and the call stack in VS Code, and explore Dart DevTools for deeper inspection.
    3. Logging in Dart: print, dart:developer and the logging PackageLearn logging in Dart: when print is enough, structured logs with dart:developer, and levels, loggers and handlers with package:logging.
    4. Memory Management and Garbage Collection in DartUnderstand how Dart manages memory: the generational garbage collector, what causes memory leaks, and how to find and prevent them.
    5. const and Performance in Dart: Compile-Time ConstantsLearn how const objects and compile-time constants improve Dart performance and memory use, and when const is and is not possible.
    6. Benchmarking and Profiling Dart CodeMeasure Dart performance correctly: Stopwatch, warm-up, JIT versus AOT, benchmark_harness, the DevTools CPU profiler and common optimizations.
