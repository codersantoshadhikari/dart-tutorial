# Backlinks for dart-tutorial.dev

Backlinks (other sites linking to you) are the "External factors" score. They cannot be added
from this code. Add them yourself, one by one, on real sites. Never buy links or use link farms:
Google can penalise the site and AdSense can reject it.

## Do these first (free, 1-2 hours total)

| # | Where | What to do |
|---|---|---|
| 1 | GitHub profile README | Add the badge or text below |
| 2 | GitHub repo of this site | Set "Website" to https://www.dart-tutorial.dev/ and add topics: dart, flutter, tutorial |
| 3 | LinkedIn | Add to "Featured" + post about the site |
| 4 | Google Business / your company sites | Link from eternovatech.com.np and smaittechnology.com.np footer: "Free Dart & Flutter tutorial" |
| 5 | dev.to, Medium, Hashnode | Write 1 short article (e.g. "30 Dart examples for beginners") and link to the matching page |
| 6 | Reddit r/dartlang, r/FlutterDev | Share only when it answers someone's question; read the rules first |
| 7 | Stack Overflow | Answer Dart/Flutter questions; link a lesson only when it really helps |
| 8 | X / Facebook groups (Flutter Nepal, Flutter India, Flutter Dev) | Share new lessons |
| 9 | YouTube | Short videos with the lesson link in the description |
| 10 | Directories | Product Hunt, AlternativeTo, Bing Places / free tutorial lists on GitHub ("awesome-flutter", "awesome-dart": open a pull request) |

HTML (your other websites):


Short bio line:

> Creator of dart-tutorial.dev – free Dart & Flutter tutorials from beginner to advanced.

## Then

Add your profile URLs to `sameAs` in `hugo.toml` (GitHub, LinkedIn, YouTube...).
Check new links in Google Search Console → Links.

## The Flutter site

Do the same for **https://flutter.dart-tutorial.dev/**: link it from your GitHub README, LinkedIn,
dev.to articles ("Flutter state management compared", "Build Snake in Flutter with Flame") and
Flutter communities. Both sites link to each other, so links to either one help both.
